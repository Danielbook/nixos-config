## Findings considered and rejected

Recorded so they aren't re-audited next run:

- **Passwordless `wheel` sudo** (`nixos/common/default.nix:129`): deliberate
  convenience on a single-user workstation. Not a finding.
- **`allowUnfree = true` in home-manager/darwin vs allowlist predicate in NixOS**
  (`flake.nix:125`): only permits *explicitly declared* packages; not an
  auto-pull risk. Cosmetic asymmetry, not security.
- **Git HTTPS→SSH rewrite** (`programs/git/default.nix:44`): intentional and
  commented (avoids the interactive HTTPS username prompt). By-design.
- **Age key sourced from Bitwarden** (`home/daniel/coruscant/default.nix`):
  documented design choice with graceful fallback; operational advice, not a
  code defect.
- **`fkill` signal arg unquoted** (`scripts/bin/fkill:6`): interactive
  self-invoked tool; `$pid` is already quoted; theoretical only.
- **`noctalia-sync` relative dest path** (`justfile:133`): symlink-attack path
  requires repo write access; speculative.
- **SSH `StrictHostKeyChecking` unset**: marginal hardening on a single-user
  machine; skip unless the maintainer wants `accept-new`.
- **statix `repeated_keys` (15 sites)**: flat `a.b = …; a.c = …;` is idiomatic
  Nix; the maintainer chose to disable the lint rather than rewrite. Folded into
  plan 001 (not a standalone finding).
